# Healthcare Revenue Cycle Analysis
An analysis of claims, denials, and collections at a fictional hospital, using Python, SQL, and Power BI

**Status:** In progress

## Overview
This project measures the health of a hospital's revenue cycle and identifies
where revenue is delayed or lost. See the [project brief](docs/project_brief.md).

## Tools
Python (pandas, NumPy), SQL, Power BI, Google Colab, GitHub

## Data
Synthetic claims dataset generated for this project. No real patient,
provider, or payer data is used.
